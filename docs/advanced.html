Virtual Windows-compatible PC
Boot your own licensed compatible x86 disk image, or a ReactOS image. Modern x64 Windows is unsupported by this emulator. Images stay local; network adapters and host integration are not configured. This is not a hardened malware sandbox.

Automate original application interaction
With the original app open and focused inside the running guest, select a trace JSON containing wait, text, keyboard scancodes and named screenshot checkpoints. This replays keyboard interactions only; it is not full native behavioral equivalence.
{"steps":[{"op":"wait","ms":1000},{"op":"snapshot","name":"initial"}]}
Boot a compatible OS, then insert the original EXE and its files into the guest as a virtual CD. Run the software within the guest. The CD is read-only; the guest disk is not written back to your selected file. Data CD supports up to 20 flat files, 128 MiB total. For larger projects or nested dependencies, insert an existing ISO.
